# CCT specialties and their sources

`specialties.json` is generated from the table below. The table has one row per specialty, in the
same order, with the length and entry grade the calculator uses and where each value comes from.
`CctSpecialtyServiceTest` fails if the two files disagree, so change them together.

## How the values were checked

- **Medical lengths** come from the GMC's page for each curriculum, which gives an indicative length
  "including core". The calculator counts from the entry grade, so the core years before it are
  taken off: 2 years for ST3, 3 years for ST4, and 2.5 years of integrated cellular pathology
  training (ICPT) for the pathology specialties.
- **Dual and triple CCTs** come from the GMC's list of approved dual CCT pairings (October 2026),
  which gives a total length for each pairing.
- **Dental lengths** come from the GDC's 2024 specialty curricula.
- **Entry grades** were checked against NHS England's 2026 person specifications.
- Lengths are indicative. A trainee's own length can still be changed in the calculator, with a
  reason.

The GMC website blocks automated access, so its pages were read from copies saved on
2026-11-09

## Status

- **Matches:** the value fits the published figure.
- **Changed:** the sources give one answer, and the value now follows it. The old value is shown.
- **Picked:** the sources give a range or disagree. The value is a suggestion awaiting the data
  owner's sign-off.
- **Decision**, **Kept** or **No source:** the value is unchanged and needs a data owner's decision.

## Not in the table

- Two approved dual pairings have no row: General psychiatry with Psychiatry of learning
  disability (8 years, from August 2026, so 60 from ST4), and Rehabilitation medicine with Sport
  and exercise medicine (6.5 years, from August 2025, so 54 from ST3).
- 2026 recruitment has entry points with no row: Clinical radiology ST3, Obstetrics and
  gynaecology ST3, Paediatrics ST3, Neurosurgery ST2, Thoracic surgery ST4 and Psychiatry of
  learning disability ST1.
